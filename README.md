# Grupo Idea · Aberturas Android

Aplicación Android compañera de **Grupo Idea Cotizador Integral v5.5**.

La app permite importar el catálogo `.gic` del software de escritorio, crear aberturas de chapa en el teléfono y exportar un proyecto `.gip` compatible con el esquema 6 del Cotizador.

## Compilación automática

GitHub Actions compila un APK de depuración en cada `push` a `main` y también admite ejecución manual.

El artefacto publicado por el workflow se llama:

`GrupoIdea-Aberturas-v1.0.0-debug`

Incluye:

- `GrupoIdea-Aberturas-v1.0.0-debug.apk`
- `GrupoIdea-Aberturas-v1.0.0-debug.apk.sha256`

## Fuente

El paquete fuente usado por la compilación está versionado como `source-android-v1.0.0.zip`.
